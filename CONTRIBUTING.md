# CONTRIBUTING

## How to Contribute
1. Read README.md, LEGAL-ETHICS.md, and the relevant protocol file. 2. Open an Issue using a template in `.github/ISSUE_TEMPLATE/`. 3. For a correction, quote the exact line, give the corrected text, and cite a source. 4. For a replication, state apparatus, code version, seeds, and decision rule you will use.

## v1.0 Frozen Rule
v1.0 is FROZEN. No changes to postulates, equations, thresholds, or protocols except: (a) corrections logged in CHANGELOG.md, (b) a new version (v1.1+) with a dated changelog entry. Preregistered thresholds must NEVER be changed after data collection begins.

## Issue Types
correction | question | replication | funding-collaboration. See `.github/ISSUE_TEMPLATE/`.

## PR Process
Fork, branch, small focused PR, link Issue, maintainer review, merge only with changelog entry. No PR may claim data that do not exist.

## Authorship
Contributions are acknowledged in CHANGELOG.md. Authorship on any future paper requires substantive intellectual contribution + responsibility for content, per lead-author decision. Funding alone is not authorship.

## Code of Conduct
See CODE_OF_CONDUCT.md. Be precise, kind, and evidence-first.
