# PRESS KIT - STM-CPM v1.0

## One-line summary
A testable proposal: causally tracked phase may improve forecasts of drifting oscillations - and five preregistered experiments say exactly what would prove it wrong.

## 3-sentence summary
Angelica Pangan (Earth Angel Ventures) defines temporal momentum as pt = E/c and continuous pi movement as phase advancing in pi-radian pi-steps. The only new claim is predictive: tracked phase features should improve forecasts only when frequency drifts, with onset near δ* = π/(8Nd). No data have been collected; five preregistered experiments with binary Supported / Not supported rules will test it.
