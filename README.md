## Abstract

**Background.** Motion is described by position, time, velocity, and acceleration. Periodic motion adds a phase variable that advances by 2pi radians per cycle, so every half cycle is an advance of pi radians. Established mechanics already supplies precise meanings for spatial momentum and, through four-momentum, for a temporal component of momentum. The original idea behind this theory is that continuous pi-related movement, meaning the uninterrupted advance of phase in steps of pi, links spatial and temporal change in a way that may carry predictive information beyond position, velocity, and acceleration alone.

**Objective.** To convert the original idea into a fully defined, testable, and falsifiable theory by (i) defining temporal momentum without ambiguity, (ii) defining continuous pi movement and its associated action quantities, (iii) specifying a causal phase-state forecasting model, and (iv) stating quantitative decision rules that determine, before any data are collected, whether the theory is supported or not supported.

**Methods.** Temporal momentum is defined as pt = E/c, the time component of four-momentum, and its phase-side companion is the action variable J, conjugate to phase. A pi-step is a phase advance of pi; the pi-step operator P_pi is a Z2 parity operation. A causal second-order phase-locked loop estimates phase from measured position and velocity. Ridge-regression forecasts using phase features (model M2) are compared with a complexity-matched fixed-period Fourier baseline (B1) on held-out data. Five preregistered experiments are specified: apparatus validation, controlled frequency-drift forecasting, a tide-gauge negative control, a sunspot-cycle natural-drift test, and a Monte Carlo robustness study.

**Results.** No empirical data have been collected. No result is claimed. All quantitative statements in this manuscript are definitions, derivations from established mathematics, or preregistered predictions and decision thresholds.

**Interpretation.** The theory makes three claims of different strength. The definitions of pt, J, and the pi-step are established physics expressed in new organizing terms. The parity property of the pi-step is an established symmetry of symmetric potentials. The only new claim is predictive: phase features add forecasting value only when the oscillation frequency drifts, with a predicted onset near delta* = pi/(8*Nd). This claim is falsified if the 97.5% one-sided confidence bound on relative error reduction at drift delta = 0.10 does not exceed 0.05 after the two-stage protocol.

**Conclusion.** The theory is bounded, internally consistent, dimensionally checked, and ready for preregistration. It claims no new physical law and no independent causal role for pi.

## Research Significance

**Original contribution.** (1) A single unambiguous definition of temporal momentum, tied to established physics. (2) A definition of continuous pi movement and the pi-step quantities (count, duration, action, parity operator). (3) A causal phase-state forecasting architecture with a gate that prevents phase use when the signal is too weak. (4) A derived critical drift delta* = pi/(8*Nd) at which a fixed-period model is predicted to lose quarter-pi-step phase accuracy. (5) A complete set of quantitative falsification rules. Novelty is asserted only as a claim pending the literature search record. It will not be claimed in any publication until that search is completed and filed.

**Potential importance.** If supported, the framework gives engineers a testable rule for when phase tracking is worth its added complexity, for example in predictive maintenance of rotating equipment, power-grid frequency studies, and forecasting of quasi-periodic natural cycles. If not supported, the result is a documented null finding that prevents wasted effort, and the definitions still serve as a clear teaching and communication standard.

**What this paper does NOT do.** It does not fill the gap with data. It fills it with definitions and a falsifiable protocol. The knowledge gap is not the existence of phase, action, or four-momentum. The gap is a single defined chain linking them to a quantitative forecasting prediction, with an onset condition for the benefit and a rule for abandoning the claim.

## Research Highlights

1. Temporal momentum is defined as pt = E/c = gamma*mc = mc(dt/dtau), the time component of four-momentum. It is established physics, not a new force or law.
2. Continuous pi movement is the uninterrupted advance of phase in pi-steps of pi radians, each lasting tau_pi = pi/omega and carrying action S_pi = pi*J = E_mech * tau_pi.
3. For a harmonic oscillator with v << c, pt = mc + omega*J/c, linking temporal momentum directly to frequency and action.
4. The pi-step operator P_pi is a Z2 parity symmetry (x -> -x, v -> -v; E, J, omega unchanged) with P_pi squared equal to the identity.
5. The constant pi does not drive motion. It appears because a half cycle spans pi radians; this manuscript explicitly rejects any independent causal role for pi.
6. Phase features from a causal phase-locked loop are predicted to improve forecasts only under frequency drift, with onset near delta* = pi/(8*Nd) and no benefit at delta = 0.
7. Five preregistered experiments with binary decision rules (Supported or Not supported) leave no outcome undefined.

## Extended Mechanisms

1. **Drift mechanism - why fixed-period models fail.** If omega_d(t) = omega0[1 + delta*sin(2*pi*t/Td)] (Eq. 37), true phase is theta(t) = omega0*t + omega0*delta*(Td/2pi)[1 - cos(2*pi*t/Td)]. A fixed-period model uses only omega0*t. The gap epsilon_theta(t) is non-negative, oscillates, reaches epsilon_max = 2*Nd*delta radians. For Nd = 10 and delta = 0.10, epsilon_max is about 2 rad - more than two quarter-pi-steps. A sinusoid with a 2-radian phase error is a poor forecast. A tracker that follows theta(t) removes this error except for loop lag.
2. **Causal phase tracking.** Quadrature signal z_n = x_n - i*v_n/omega_hat_n equals A * e^(i*theta) for x = A cos theta, v = -A*omega sin theta. Phase detector compares z_n with current estimate; loop updates theta_hat and omega_hat (Eqs. 19-20). Gains follow standard second-order design, xi = 0.707, omega_L = 0.1*omega0 (Eq. 21). Only samples up to time t are used, so the estimator is causal. First 5*T0 of each record are discarded as loop warm-up. When velocity is not measured (E3, E4), v is replaced by causal backward difference (x_n - x_{n-1})/Delta_t, and omega_hat in the quadrature step is taken from the previous loop state.
3. **Gate mechanism.** Phase is undefined when amplitude is near zero. Gate g_n sets phase features to zero when A_n < g_min * A_bar, A_bar = median training amplitude, g_min = 0.1 (Eq. 22). This prevents random phase values and removes an obvious route for false improvement or false degradation.
4. **Operator mechanism - pi-step parity check.** For a symmetric potential, P_pi gives a built-in consistency test: if estimated phase is correct, signal at tau_pi later should be the negative of signal now. Residual rho_P (Eq. 36) is measured in E1 and can be used as a quality check on any later dataset.

**Common analysis (fixed before data).** B0: x, v, a + 5 lags at tau_s = T0/20. B1: B0 + fixed-period Fourier cos k*omega0*t, sin k*omega0*t, k = 1..3, omega0 = FFT peak (zero-padded) of training segment, fixed over test. M2: B0 + g_n*cos k*theta_hat, g_n*sin k*theta_hat, k = 1..3. Tracker: second-order PLL, xi = 0.707, omega_L = 0.1*omega0, warm-up 5*T0, gate g_min = 0.1. Fitting: ridge, lambda in 1e-4, 1e-3, 1e-2, 1e-1, 1, 10, 100 by blocked CV inside training only; features standardized with training statistics. Horizons h = 0.25*T0, 0.5*T0, T0; primary h = 0.5*T0. Primary metric Delta = 1 - RMSE_M2 / RMSE_B1 on held-out segments. Intervals: cluster bootstrap over runs (E2), moving-block bootstrap (E3, E4); 10,000 resamples; lower = 2.5th percentile, upper = 97.5th percentile (one-sided 97.5%). Leakage control: tracker state, omega0, lambda, standardization, gate reference A_bar from training only; test data sealed until code frozen. Threshold constants: Delta_min = 0.05; no-benefit bound 0.02; planning Delta_design = 0.15; planning sigma_Delta = 0.12.

**Sample size / power.** Loss-differential effective size N_eff = N(1-rho)/(1+rho) (32); N_req = [(z1-alpha + z1-beta)*sigma_d / mu_d]^2 (33), one-sided alpha = 0.025, power 0.90 (z-sum = 3.2415). For sigma_d/mu_d = 5, rho = 0.9: N_req = 263, N about 4,990 samples. For E2 (unit = run): n_runs = [3.2415 x 0.12 / 0.10]^2 = 15.1, rounded up to 16. Stage 1 uses 20 runs/delta (25% above requirement); Stage 2 uses 40 runs/delta. Planning values are assumptions, not results; revisable only before data collection, using E5.

**Order / gating.** 1) E1 validation - must pass before E2 uses apparatus. 2) E5 Monte Carlo - run before E2 so planning values may be updated once, before data collection, and locked in registration. 3) E2 - only after E1 passes and registration filed. 4) E3 - independent of E2; after registration filed. 5) E4 - independent of E2; after registration filed.
